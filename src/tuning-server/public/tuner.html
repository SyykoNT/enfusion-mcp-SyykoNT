Vehicle tuner

Apply writes the changed values as inline overrides into this vehicle's own .et, never into a shared .conf, and only into a block that already exists in that .et. For a missing block the server answers: "Add the override in Workbench first; this tool never creates blocks. Nothing was written." Close the prefab in Workbench before applying.

Where a value comes from: own is set in this .et; inherited from names the parent prefab, the vanilla original of this file or the .conf it came from; template is the component template default; unset means no file sets it (counted as 0 in the curves).
